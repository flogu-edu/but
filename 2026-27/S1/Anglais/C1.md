## Language work:
### Present perfect:
- We use the Present perfect to describe past actions w/ present relevance

#### Vocabulary:
- Since = depuis : 
    - "for" + duration
    - "Since" + start date
- Yet = Pas encore
- Never ever = Jamais
- Already = Déjà
- Just = Viens de

### Past simple:
- We use teh Past simple to describe completed actions in the past.
